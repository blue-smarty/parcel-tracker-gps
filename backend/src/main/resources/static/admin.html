ON-DEMAND DELIVERY

Service levels

Targets apply to new bookings only and are not guarantees. Direct has highest dispatch priority but does not reserve a courier or enforce a direct route.

Express must be no longer than General. On-demand services use the standard estimate rate.

DELIVERY PRICING

Estimate rates

These rates determine estimates for new parcels. Existing parcel estimates are not changed.

Radius distance bands

The distance charge is fixed per band. The last band is open-ended.

Cubic weight per item is length × width × height (cm) divided by the divisor. Item weights are multiplied by quantity and summed. Cubic modes require individual item dimensions.

Formula: (base fee + route/radius distance charge + weight × kilogram rate) × speed multiplier. Radius distance is the straight-line distance between the geocoded pickup and delivery addresses.

CUSTOMER EMAIL

SMTP settings

Used for customer password reset email. Enable password recovery and set its public URL in deployment configuration. Set the SMTP password as the SPRING_MAIL_PASSWORD deployment secret; it is never stored here. Saving overrides deployment mail host settings.
