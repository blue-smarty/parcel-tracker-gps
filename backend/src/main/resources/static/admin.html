DELIVERY COVERAGE

Service area

When enabled, pickup and delivery addresses must be verified within the 31 Melbourne metropolitan council areas. Vicmap and TomTom must be available. Existing deliveries are not changed.

Unrestricted allows bookings outside Melbourne. Changes are recorded in the server audit log.

DELIVERY PRICING

Estimate rates

These rates determine estimates for new parcels. Existing parcel estimates are not changed.

Formula: (base fee + distance × kilometer rate + weight × kilogram rate) × speed multiplier.
